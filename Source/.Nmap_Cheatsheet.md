## Quick List

- `nmap -sn -n target/24`                               # Ping sweep
- `nmap -T4 -F target/24`                               # Fast Initial Recon
- `nmap -A -T4 target`                                  # Intense Scan
- `nmap -sS -sV -O -sC -T4 target`                      # Custom Intense Scan
- `nmap -p- -sS -sU -sV target`                         # Full TCP + UDP (Heavy)
- `nmap -p- -sS -sV -T4 target`                         # Full TCP Port Scan + Service Detection
- `nmap -Pn -sS -sV target`                             # Firewall / ICMP-Blocked Hosts
- `nmap -sC -sV -T3 -vv -oN scan.txt target`            # Default Scripts + Service Detection
- `nmap -sS -T0 -f --data-length 200 -D RND:10 target`  # Ultra-stealth scan

## Target Specification

Define exactly which IPs, ranges, or subnets Nmap should scan during network reconnaissance.

Can pass hostnames, IP addresses, networks, etc.
(i.e., `scanme.nmap.org`, `microsoft.com/24`, `192.168.1.1`; `10.0.0-255.1-254`)

| EXAMPLE                   | DESCRIPTION                             |
| ------------------------- | --------------------------------------- |
| `nmap target-254`         | Scan a range                            |
| `nmap scanme.nmap.org`    | Scan a domain                           |
| `nmap target/24`          | Scan using CIDR notation                |
| `nmap <target1> <target2>`| Scan specific IPs                       |
| `nmap -exclude target`    | Exclude listed hosts                    |
| `nmap -iL targets.txt`    | Scan targets from a file                |
| `nmap -iR 100`            | Scan 100 random hosts (CAREFUL USING!)  |

## Host Discovery

Identify which hosts are online before running a full scan or when skipping port scans entirely.

|SWITCH | EXAMPLE                           | DESCRIPTION                               |
| ----- | --------------------------------- | ----------------------------------------- |
| `-sL` | `nmap -sL 192.168.1.1/24 -sL`     | List Scan — list targets only             |
| `-sn` | `nmap -sn 192.168.1.1/24 -sn`     | Disable port scanning (Host only)         |
| `-Pn` | `nmap -Pn 192.168.1.1-5 -Pn`      | Disable host discovery. Port scan only    |
| `-PS` | `nmap -PS 22-25,80 192.168.1.1-5` | TCP SYN discovery on port x.              |
| `-PA` | `nmap -PA 22-25,80 192.168.1.1-5` | TCP ACK discovery on port x.              |
| `-PU` | `nmap -PU 53 192.168.1.1-5`       | UDP discovery on port x. (def=port 40125) |
| `-PR` | `nmap -PR 192.168.1.1-1/24`       | ARP discovery on local network            |
| `-n`  | `nmap -n 192.168.1.1`             | Never do DNS resolution/Always resolve    |

## Port Specification

Target specific ports, ranges, or combinations of TCP & UDP ports for more precise scans.

| SWITCH & Example      | DESCRIPTION                                               |
| --------------------- | --------------------------------------------------------- |
| `-p-`                 | Port scan ALL ports                                       |
| `-p 80,101-204`       | Port range                                                |
| `-p U:53,T:21-25,80`  | Port scan multiple TCP & UDP ports                        |
| `-p http,https`       | Port scan from service name                               |
| `-p-65535`            | Leaving off initial port in range makes it start port 1   |
| `-p0-`                | Leaving off end port range makes scan go to port 65535    |
| `--top-ports 1000`    | Port scan the top x ports                                 |
| `-F`                  | Fast port scan. Scan fewer ports than def scan (100 ports)|
| `-r`                  | Scan ports sequentially - don't randomize                 |

## Service and Version Detection

Detect which services are running & attempt to identify software versions & configurations.

| SWITCH                      | DESCRIPTION                                                 |
| --------------------------- | ----------------------------------------------------------- |
| `-A`                        | Enables OS/Version detection, Script scan, & Traceroute     |
| `-sV`                       | Attempts to determine version of service running on port    |
| `-sV -version-all`          | Try every probe (Intensity 9). Slower + High possibility of correctness |
| `-sV -version-intensity <#>`| Intensity level 0-9. Higher increases chance of correctness |

## OS Detection

Use TCP/IP fingerprinting to guess operating system of target hosts.

| SWITCH              | DESCRIPTION                                             |
| ------------------- | ------------------------------------------------------- |
| `-A`                | OS/Version detection + Script scanning + Traceroute     |
| `-O`                | Remote OS detection using TCP/IP stack fingerprinting   |
| `--osscan-limit`    | If 1 open + closed TCP port NOT found, won't detect OS  |
| `--osscan-guess`    | Makes Nmap guess more aggressively                      |

## Timing and Performance

Adjust scan speed & stealth based on target environment and detection risk.

| SWITCH  | DESCRIPTION                                               |
| ------- | --------------------------------------------------------- |
| `-T0`   | Paranoid (0): Intrusion Detection Sys evasion             |
| `-T1`   | Sneaky (1): Intrusion Detection System evasion            |
| `-T2`   | Polite (2): slow to use less bandwidth + target resources |
| `-T3`   | Normal (3): which is default speed                        |
| `-T4`   | Aggressive (4): assumes on fast network                   |
| `-T5`   | Insane (5): assumes extraordinarily fast network          |

## Output Formats

Save your scan results in formats like *normal text*, *XML*, or *grepable output* for later analysis.

| SWITCH                    | DESCRIPTION                                   |
| ------------------------- | --------------------------------------------- |
| `-oN normal.file`         | Normal output to file                         |
| `-oX xml.file`            | XML output to file                            |
| `-oG grep.file`           | Grepable output to file                       |
| `-oS sKrIpT.file`         | sCrIpt kIddi3 (for fun)                       |
| `-oA results`             | Output in the 3 main formats at once          |
| `-oG -`                   | Grepable output to screen (`-oN -`, `-oX -`)  |
| `-v`                      | Increase verbosity level (`-vv` or more for greater effect) |
| `-d`                      | Increase debugging level (`-dd` or more for greater effect) |
| `--open`                  | Only show open (or possibly open) ports       |
| `--iflist`                | Print host interfaces and routes (debugging)  |
| `--reason`                | Show why port's in certain state (`-vv` same) |
| `--resume <file>`         | Resume an aborted scan                        |
| `--packet-trace`          | Show all packets sent & received              |
| `--stylesheet <path/URL>` | XSL stylesheet to transform XML output to HTML|

## Firewall / IDS Evasion and Spoofing

Bypass security measures using packet fragmentation, spoofed IPs, & stealthy scan methods.

|SWITCH & EXAMPLE                         | DESCRIPTION                                 |
| --------------------------------------- | ------------------------------------------- |
| `-f`, `--mtu <val>`                     | Fragment packets (optionally w/given MTU)   |
| `-g <port>`                             | Use given source port number                |
| `-D decoy1,decoy2,<YOU>,decoy3,<target>`| Cloak scan with decoys.                     |
| `-S 192.168.1.100 192.168.1.1`          | Spoof source IP (requires `-Pn`)            |
| `--spoof-mac <mac_addr/prefix/vendor>`  | Spoof your MAC address                      |
| `--badsum`                              | Send packets w/bogus TCP/UDP/SCTP checksum  |

Aggressive IDS evasion example (spoofing)
`nmap -f -T0 -n -Pn --data-length 200 -D 192.168.1.101,192.168.1.102,192.168.1.23 192.168.1.1`
Alternative — an example of a quieter scan
`nmap -p 22,80,443 -sT -T2 -n -Pn target`

## Nmap Scripting Engine (NSE)

Enhance your scans with Nmap’s scripting engine for automation and deeper inspection.

### General NSE Usage

| COMMAND                           | DESCRIPTION                                     |
| --------------------------------- | ----------------------------------------------- |
| `--script default`, `-sC`         | Scan w/default (safe) NSE scripts               |
| `--script "not intrusive"`        | Scan w/default scripts, but exclude intrusive ones |
| `--script=<script>`               | `--script=banner` Scan with specific script     |
| `--script=<script_group>`         | `--script=http,banner` Scan with multiple script groups/categories |
| `--script vuln`                   | Scan using vulnerability detection scripts      |
| `--script=vulners`                | Scan using Vulners scripts                      |
| `--script-trace`                  | Show all data sent and received                 |
| `--script-updatedb`               | Update NSE script database                      |
| `--script-help <script>`          | Find help for a specific script                 |
| `--script ipidseq 192.168.1.0/24` | List idle candidates for IPID sequence scanning |

### NSE Script Categories

Explore various categories of NSE scripts to target specific aspects of network security.

| CATEGORY          | DESCRIPTION                                                 |
| ----------------- | ----------------------------------------------------------- |
| `all`             | Run ALL scripts (can be over 600). Use with **CAUTION**.  |
| `auth`            | Checks for authentication bypass vulnerabilities.           |
| `backdoor`        | Scans for known backdoors on target system.                 |
| `broadcast`       | Send broadcast packets to discover hosts/services on network|
| `broadcast-ping`  | Send broadcast pings on network to discover active hosts.   |
| `brute`           | Brute force password auditing against service.              |
| `default`         | Run basic set of scripts for general reconnaissance.        |
| `discovery`       | Gathers info about target, such as open ports & services.   |
| `dos`             | Attempts to identify/exploit DOS vulns. **USE W/EXTREME CAUTION** |
| `exploit`         | Attempts to exploit vulnerabilities on the target.          |
| `external`        | Leverages external sources to gather info about target.     |
| `firewall-bypass` | Attempts to detect & exploit firewall rule misconfigurations|
| `fuzzer`          | Sends unexpected or random data to services to identify potential vulns |
| `http-brute`      | Performs brute force password audit against HTTP authentication |
| `intrusive`       | Scripts that may be disruptive or cause service interruptions; **USE W/CAUTION** |
| `malware`         | Checks for indications of malware infections on target      |
| `safe`            | Runs scripts deemed safe & unlikely to cause disruptions    |
| `smb-vuln-*`      | Executes a suite of scripts targeting SMB vulnerabilities   |
| `version`         | Determines service versions running on open ports           |
| `vuln`            | Runs suite of vulnerability detection scripts against target|
| `vulners`         | Runs Vulners scans                                          |

## Specific NSE Script Examples

### Vulnerability Scanning (vuln)
```bash
nmap -sS -sV -p 445 --script vuln 10.10.10.11 -vv   # Vulnerability scanning on host
nmap -p 445 --script smb-vuln-ms17-010 target       # Check for MS17-010 (EternalBlue) vulnerability
nmap -T2 -sV --script vuln 192.168.250.0/24         # Scan for Vulnerabilities across a subnet
```

Scans random LIVE IP's *(USE WITH CAUTION)*
`nmap -n -Pn -p 80 --open -sV -vvv --script banner,http-title -iR 1000`

### Popular NSE Scripts

```bash
nmap --script http-robots.txt 192.168.1.1         # HTTP robots.txt
nmap --script http-title 192.168.1.1              # HTTP title
nmap --script ssl-cert -p443 192.168.1.1          # SSL certificate info
nmap --script smb-vuln-* -p445 192.168.1.1        # SMB vulnerabilities
nmap --script smb-brute -p445 192.168.1.1         # SMB brute force
nmap --script ftp-anon -p21 192.168.1.1           # FTP anonymous login
nmap --script mysql-info -p3306 192.168.1.1       # MySQL info
nmap --script ssl-heartbleed -p443 192.168.1.1    # Heartbleed vulnerability
nmap --script vuln 192.168.1.1                    # Vulnerability scan

# DNS zone transfer
nmap --script dns-zone-transfer --script-args dns-zone-transfer.domain=example.com -p53 ns1.example.com
# Wordpress password/username
nmap --script=http-wordpress-brute --script-args userdb=users.txt,passdb=passwords.txt 192.168.1.1
# SSH brute force
nmap --script ssh-brute --script-args userdb=users.txt,passdb=passwords.txt -p22 192.168.1.1
# Shellshock vulnerability
nmap --script http-shellshock --script-args uri=/cgi-bin/test.sh 192.168.1.1

nmap --stats-every 2s -sS -R -PS -F -sV -sC --script vuln --script-timeout 30 -O --osscan-guess -T4 -oN NMAP.txt -v -d 192.168.1.1

# Parsing NMAP Reverse DNS Lookup
nmap -R -sL -Pn -dns-servers dns svr ip range | awk '{if( ($1" "$2" "$3)=="NMAP scan report")print$5" "$6}' | sed 's/(//g' | sed 's/)//g' dns.txt

```

## Real-World Workflows & Common Scenarios

Practical sequences of Nmap commands for typical assessment tasks.

### Network Discovery Workflow

A step-by-step approach to identify live hosts and open ports on a network.
```
nmap -sn 192.168.1.0/24                           # Step 1: Discover live hosts
nmap -sS -T4 --top-ports 1000 192.168.1.0/24      # Step 2: Quick port scan of top 1000 ports
nmap -sS -sV -O -sC target                        # Step 3: Intense scan of interesting hosts (replace 'target')
nmap -p- -A -T4 target                            # Step 4: Comprehensive scan (all TCP ports, aggressive)
```

### Complete Network Audit

```bash
# Comprehensive network audit
sudo nmap -sS -sV -O -p- --script "default and safe" -oA audit_results 192.168.1.0/24

# Fast initial scan
nmap -sn 192.168.1.0/24 -oG - | awk '/Up$/{print $2}' > live_hosts.txt

# Detailed scan of live hosts
sudo nmap -sS -sV -O -A -iL live_hosts.txt -oA detailed_scan
```

### Web Server Assessment

Commands for identifying and enumerating web services.
```
nmap -sS -p 80,443,8080,8443 --open 192.168.1.0/24    # Find common web servers
nmap -sS -sV --script http-* target                   # Enumerate HTTP services with various scripts
nmap --script vuln -p 80,443 target                   # Check for common web vulnerabilities
nmap -p 80,443 --open 192.168.1.0/24 | grep "open"    # Find Web Server and filter output

# Aggressive HTTP enumeration
nmap -p 80,443 -sV --script=http-enum,http-title,http-headers target

# HTTP brute force w/custom wordlist.
nmap --script http-brute --script-args userdb=users.txt,passdb=pass.txt target
```

### SMB/NetBIOS Enumeration

Commands for discovering and assessing SMB/NetBIOS services.
```
nmap -sV -p 139,445 192.168.1.0/24                  # SMB service detection across a subnet
nmap --script smb-enum-* -p 445 target              # SMB enumeration scripts on a target
nmap --script smb-vuln-* -p 445 target              # SMB vulnerability check on a target
nmap -sU --script nbstat -p 137 192.168.1.0/24      # NetBIOS name discovery via UDP
```

### Scanning Android Devices

Specific commands for identifying potential services & vulnerabilities on Android devices.
```
nmap -p 5555 target                         # Check for ADB exposure (high-risk if open)
nmap -p- -Pn --open target                  # Scan all TCP ports + listening services (no ping)
nmap -O --osscan-guess target               # Identify device behavior (OS fingerprinting)
nmap -sT -sV --version-light target         # Detect Android-specific services
nmap -sU -Pn --top-ports 100 target         # Scan UDP (where Android services often hide)
```

# Zenmap Presets

These are frequently used Nmap command combinations, often found as presets in GUI tools like Zenmap.

1. Intense scan: `nmap -T4 -A -v`
  - OS/version detection, scripting, traceroute, & verbose. (only version detection & scripting run if not root)
2. Intense scan plus UDP: `nmap -sS -sU -T4 -A -v`
  - Intense scan including TCP SYN and UDP ports
3. Intense scan, all TCP ports: `nmap -p- -T4 -A -v`
  - Intense scan across all 65535 TCP ports
4. Intense scan, no ping: `nmap -T4 -A -v -Pn`
  - Intense scan without checking if targets are up first (useful when target ignores usual host discovery probes)
5. Ping scan: `nmap -sn`
  - This scan only finds which targets are up & doesn't port scan them
6. Quick scan: `nmap -T4 -F`
  - Faster than normal scan because uses aggressive timing template & scans fewer ports (top 100)
7. Quick scan plus: `nmap -sV -T4 -O -F --version-light`
  - Quick scan with OS/Version detection and light version intensity
8. Quick traceroute: `nmap -sn --traceroute`
  - Traces paths to targets without doing a full port scan
9. Slow comprehensive scan: `nmap -sS -sU -T4 -A -v -PE -PS80,443 -PA3389 -PP -PU40125 -PY --source-port 53 --script all target`
  Comprehensive, slow scan. Scans every TCP/UDP port. Many probes sent for host discovery (highly intrusive). Use with extreme caution
